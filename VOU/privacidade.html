Política de Privacidade

Transparência e proteção dos teus dados pessoais.

Na VO.U. – Associação de Voluntariado Universitário, a transparência é fundamental. Como o nosso website é essencialmente informativo, a nossa política de dados é muito simples:

1. Como recolhemos os teus dados?

O nosso website não possui formulários de registo. A única forma de recebermos dados pessoais teus é através do contacto voluntário que estabeleças connosco via e-mail (ex: para geral@vou.pt).

2. Finalidade e Conservação

Utilizamos o teu nome e endereço de e-mail exclusivamente para:

  • Responder às tuas dúvidas ou pedidos de informação;
  • Gerir a tua futura integração no Banco de Voluntários, caso nos envies uma candidatura por correio eletrónico.

Os teus dados de contacto serão conservados apenas pelo período necessário para dar seguimento ao teu pedido ou enquanto mantiveres uma ligação ativa com a associação.

3. Links para Redes Sociais

O nosso website contém botões para as nossas páginas oficiais no Instagram, Facebook e LinkedIn.

Nota importante: Ao clicares nestes botões, serás redirecionado para plataformas externas. A VO.U. não controla nem é responsável pela forma como estas redes sociais tratam os teus dados ou utilizam cookies. Recomendamos que consultes as políticas de privacidade de cada uma destas plataformas (Meta e LinkedIn).

4. Os Teus Direitos

De acordo com o RGPD, podes a qualquer momento solicitar o acesso, retificação ou eliminação dos teus dados (e-mails e contactos).
